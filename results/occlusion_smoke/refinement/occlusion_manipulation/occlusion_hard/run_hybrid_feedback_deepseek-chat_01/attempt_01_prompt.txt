SCENE NAME:
Three-layer occlusion with mandatory restoration

DESCRIPTION:
A Lego-like structural occlusion scene with a three-layer dependency chain. The top occluder O3 blocks O2, O2 blocks the front ground occluder O1, and O1 blocks access to the target brick T1. The robot must remove all three occluders in dependency order, temporarily store them, relocate the target, and then reconstruct the remaining occluder dependency chain. Restoration reconstructs the occluder structure after target relocation; the original O1-to-T1 occlusion is not restored because T1 has moved to the goal location.
